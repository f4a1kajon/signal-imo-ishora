# SIGNAL — Imo-ishora

SIGNAL — brauzerda ishlaydigan imo-ishora prototipi. Ilova faqat foydalanuvchi o‘rgatgan qo‘l harakatlarini taniydi; universal tarjimon emas.

## Deploy

Vercel’da ushbu repozitoriyni import qiling. Build command yoki output directory kerak emas; `index.html` statik sahifa sifatida ishlaydi. Kamera uchun HTTPS va brauzer ruxsati talab qilinadi.

Tarjima Chrome Translator’ni sinab ko‘radi; u mavjud bo‘lmasa, matn MyMemory xizmatiga yuboriladi. Maxfiy matn kiritmang.
